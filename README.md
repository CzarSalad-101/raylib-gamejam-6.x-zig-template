This is a starting template for the [Raylib 6.x Game Jam](https://itch.io/jam/raylib-6x-gamejam)
using Zig 0.16.0 and the [raylib-zig](https://github.com/raylib-zig/raylib-zig/) bindings.

To get this running:
- you need to modify a single line in the Zig Std Library. You can read the change [here](https://codeberg.org/ziglang/zig/commit/2eda0ef8f075aa24fecdd792a523f260d9177ea8).
- you also need to copy zig-pkg\raylib-6.0.0-whq8uCSwLgWWeF3ec3dbG6Rr36SLFL-s2WJ1Q_2E22Bb\src\shell.html to zig-pkg\raylib_zig-6.0.0-KE8REDJ4BQBu7lKwYNt6R4j5ywPeS37zqW6zrtjCcRwH\src\shell.html
